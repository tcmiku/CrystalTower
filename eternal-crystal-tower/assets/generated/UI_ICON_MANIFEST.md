## 生成规格

- 模式：Codex 内置 ImageGen。
- 风格：暗色宇宙晶塔、手绘游戏 UI、晶体与秘术机械、克制辉光、小尺寸清晰轮廓。
- 约束：固定 5 × 3 网格、单格单图、无文字、无数字、无边框、统一视角与留白。
- 原始生成图保留在 Codex 生成目录，项目内文件是运行时副本。

新增图标时优先复用第三行预留格位；需要扩充时应创建新版本图集与对应 CSS 类，不要改变现有格位顺序，以免旧界面取错图。
