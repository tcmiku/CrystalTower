# 第二批模块扩展 · 实现说明

2026-09-14，基于 `0da59b1` 完成收尾。沿用 `design/MODULE_EXPANSION.md` 的玩法、当前第一章网格装配和简体中文界面。本批完成剩余四件模块及两件武器的四种专精，游戏现有 16 种可安装模块。

## 玩法与边界

| 模块 | 已实现行为 |
| --- | --- |
| 熔晶射线塔 | 2 格、150 金币，射程 300；持续照射最多 3 秒，伤害从塔攻击 0.8 倍／秒逐步增到 2 倍／秒，然后散热 2 秒。II 级蓄热加快，III 级散热 1.5 秒。换目标重置增幅但不延长持续照射上限。 |
| 晶簇布雷器 | 2 格、130 金币，每 4 秒布雷，最多 3 枚，单枚存活 15 秒；接敌后爆炸，伤害为塔攻击 2.5 倍、半径 70。II 级存量 4，III 级部署间隔 3.2 秒。八向朝向独立于占格，转向或拆装回收现存晶雷。 |
| 共鸣导桥 | 1 格、90 金币，横／纵向可旋转；仅把两端正对的一个反应器和一个武器连接起来，元素触发概率效率为 70%／85%／100%。不传递直接邻接的基础伤害加成，不串联导桥，直接邻接优先。 |
| 储能晶匣 | 1 格、100 金币，绑定相邻轻炮、重炮或迫击炮；多个候选时手动指定。装填完成且无射程内目标时蓄能，下一次开火每层增伤 25%，持续射击间隔增加 10%。II 级蓄能间隔 2→1.5 秒，III 级层数上限 3→4。 |

射线专精“切割扇面”用固定低倍率照射 60° 内多目标；“熔穿焦点”延长到 5 秒，最高每秒伤害 3 倍，散热 3 秒。晶雷专精“连锁雷场”在 130 范围内按 0.15 秒间隔传递引爆，单雷伤害降低 25%；“阻滞雷场”留下持续 3 秒减速区，普通敌人减速 45%、首领 15%，爆炸伤害降低 35%。

射线每 0.5 秒最多尝试一次元素附加。晶雷部署时保存元素，在自身爆炸时只结算一次。暂停不推进计时，重整和改绑清空储能；射程内有目标时更换集火规则不能刷充能。

## 画面与操作

四件模型与 SVG 图标、射线蓄热与散热、晶雷触发范围与寿命环、储能晶点、导桥端点高亮已接入。卡片写明条件与代价。R 旋转导桥，落回原格确认；储能晶匣卡片可切换绑定武器。沿用金币、每类一件、三档升级、共享边邻接和现有重整规则。

模型工坊提供第二批组合预设。16 张卡片的静态缩略图共用一个临时渲染器，仅最多 8 张可见卡片保留动画上下文，避免扩容后超过浏览器 WebGL 上限。

## 运行与验证

`npm start`；另设端口时，PowerShell 先执行 `$env:PORT=4184`。试玩地址：`/?preview=chapter-one-modules-two&seed=93`，模型工坊：`/module-model-preview.html`。

试玩预装 12 格组合：火反应器—导桥—轻炮、布雷器、储能晶匣、射线塔、迫击炮、引力锚。空格开始；前几秒蓄能与布雷，敌群接近后观察充能释放、射线和引爆；T 打开装配，Esc 返回。
