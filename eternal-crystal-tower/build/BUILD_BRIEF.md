# 《永耀晶塔》构建说明

## 第二章第一版 · 极夜航道（2026-08-31）

- 目标：把第一章的中央晶塔防守变成海上航母防卫纵切；防御塔替换为“永耀蜂巢舰”，第二章只加载独立的舰载无人机科技树，不显示也不允许购买第一章科技。
- 可玩入口：完成并修复第一章节点后，从大本营选择第二章；开发验收可直接打开 `/?chapter=2&seed=71`。
- 首版范围：生图极夜海域、永耀蜂巢航母、四态舰载无人机、四类敌舰图集、四条航路、生图终局“渊潮王舰”、第二章舰队生成表、章节专属 UI 文案、核心能源/战绩/节点修复和第三章解锁占位。
- 战斗取舍：航母本体不主动索敌或开火，只承担承伤、回收与舰载机支援；开局三支无人机默认主动出击，无人机伤害为 275%、能源为 125%，是第二章的常规主武器。金币与永久残片由磁吸回收甲板独立处理，G 键只负责召回充能与再次出击。
- 科技树重构：主轴逐步编入截击战斗机、雷击攻击机与重型轰炸机，并通过甲板弹射器、联合编队齐射和紧急再出动完善航空群；航母支援轴仍负责回收、中继与维修。
- 出击循环：每架舰载机独立执行“发现敌舰 → 离舰 → 抵达固定编队点 → 环绕开火 → 弹药耗尽返航 → 甲板补能装弹 → 再次出击”，不再持续贴近目标造成接触伤害。
- 编队战术：第二章将四个目标协议替换为航母护航、集中打击、分散清扫和分层协同；切换战术时，已出击单位先返航重组，再按新规则分配目标。
- 战斗可读性：无人机进入武器半径即可完成接敌编队，避免被移动目标拖在出航阶段；机体旁实时显示当前弹药/最大载弹量。
- 前期平衡：威胁 I–III 且尚未解锁进阶航空科技时，基础战斗机获得临时弹药与伤害加成，保证航母能撑到攻击机、轰炸机科技；重型载荷等级会真实提高轰炸机单发伤害。
- 首版平衡：渊潮王舰沿用成熟的四命核终局机制，单命核生命为原模板的 68%，避免威胁 XII 版本因复用威胁 XX 数值而拖长。
- 机型分工：战斗机优先高速与远程敌舰，攻击机优先巡洋舰和重甲舰，轰炸机优先首领、精英与大型目标并造成范围爆炸；机型通过科技解锁并按机库序列混编。
- 复用边界：保留原引擎敌人行为、技能、遗物、输入与结算协议；科技目录、节点前置、成本和可购买集合按章节隔离，第一章默认路径与五架无人机上限不变。
- 美术资产：第二章五张专用素材由 OpenAI 内置 ImageGen 生成并复制到 assets/generated；渲染器按章节选择海域、航母、敌舰、无人机与终局王舰，缺图时回退 Canvas 占位。
- 动态海域：ImageGen 将原海域拆为透明礁体/残骸/浮标/雾前景；Canvas 在其下绘制静海与风暴两档波幅、双层流纹、磷光掠影和超载映照。透明前景缺失时回退原始静态海域。

## 必须保真

- 中央固定晶塔自动攻击，四周怪潮持续收紧。
- 金币初始可由鼠标滑过或点击回收，未锁定的掉落在 7 秒后闪烁、10 秒后消失；已经开始任何回收轨迹的金币不得中途失效。玩家投入火力、环刃、经济、元素四分支科技树；火力分支内的炮膛专精提供破城/裂晶二选一路线。科技树使用可由 `T` 开关的独立大面板，打开时自动暂停，关闭后遵守原有暂停状态；常驻右栏保留入口、摘要和无人机模式按钮。无人机达到 3 架后才可解锁晶塔磁吸核心，核心仅在护航模式每 5 秒批量吸收场上遗响碎片与核心残片。
- 每次怪潮唯一精英必须确定性随机获得护盾、狂奔、吞金、分裂之一并执行真实行为；十级首领必须按 70%/40% 生命门槛切换冰霜、火焰、雷电抗性，每阶段重建四枚优先目标锚点。威胁 15 必须进入独立巨型首领战，暂停常规刷怪，并以互斥状态施放炮击、召唤、射线和堡垒技能；技能必须先显示攻击预兆。巨兽每局携带一个可见随机词条，半血后狂化、清除并免疫冰冻，同时强化伤害、移速与施法频率。
- 右侧常驻四种目标协议，允许鼠标点击或 `R` 键循环：近卫按距离、猎杀号优先首领/精英/咒晶怪、破阵按预计接触时间、雷达优先远程单位。协议同时影响晶塔弹、晶刃炮膛和攻击无人机；腐化锚点不再强制抢占目标，只有玩家点击后才覆盖协议排序 5 秒。
- 无人机科技最多升至五架；无人机护航/攻击必须由共享电量约束：攻击停止磁吸资源吸收和无人机拾币，持续耗电且撞击额外耗电，归零强制返航；护航被动充电，实际带回金币额外充电。无人机分支增加拾荒、拦截、猎杀三项科技，分别强化拾币价值与速度、抵挡一次重击、标记精英并令所有炮弹增伤。
- 主动技能必须保留风险选择：超载期间再次触发会提前释放击退并保留原冷却；晶愈补满护盾会装填一次受击晶片爆炸；星落采用手动扇区瞄准，确认前实时预览方向，取消不消耗冷却。
- 四枚首领锚点必须拥有不同战斗职责：护盾减伤、修复回血、召唤增援、过载提速。画布点击某枚锚点只临时锁定 5 秒，到期、摧毁或阶段重建后恢复当前自动协议。
- 三段塔形、发射暖金旋刃弹的环绕晶刃、磁吸核心完成后开放常驻右栏无人机近战攻击/护航切换、四个主动技能和阵亡后的星尘研究；晶愈的过量治疗转护盾，超载积热并在结束时击退、过热后短暂降速，星落只轰击玩家确认的手动扇区，金潮归塔直接结算全场金币。
- 元素分支包含冰霜、火焰、雷电三项一次性科技，均同时检查威胁、金币、前置科技和晶塔等级。元素弹可冻结、灼烧或连锁，首领承受的特殊效果必须衰减；三项可叠加安装，并在晶塔左肩、右侧与塔顶增加互不遮挡的独立生图模块。元素弹主体及六角冰封环、旋转余烬环、折线连锁电弧必须使用内置生图模型生成的项目内 PNG；弹丸素材主轴必须跟随速度方向、尺寸不得遮住小怪，并在首次命中后立即移除。各元素以轮廓、色彩、尾迹和动画共同保持可读，程序图形仅作资源失败回退。
- 三项元素科技全部完成后，塔阶节点开放第三次升阶“万象晶塔”，费用 2400 金币。终极形态使用内置生图模型生成的完整项目内 PNG，将冰霜、炉火与雷电结构融合进同一塔身；切换后不得继续绘制三件旧外挂，并全面提升伤害、攻速、射程、生命与齐射数量。

## 永久 2× 时流

- 威胁 10 首领被击破时写入 `unlocks.doubleSpeed=true`，并用首次守望引导提示 2× 时流的用法；旧存档缺少字段时安全回退为未解锁，清档会同步移除该功能。
- 顶部 `1× / 2×` 按钮和 `X` 键负责切换。未解锁状态仍可点击查看条件；解锁后立即可在当前局启用，刷新后默认回到 1×，但按钮保持可用。
- 倍率作用于固定步累计器，完整覆盖战斗时间线；单帧最多补算 16 步，允许 100ms 帧间隔下的 2× 追帧。暂停、科技树和排行榜弹层逻辑不变。
- 验证预览：`?preview=speed` 直接显示 2× 激活态，仅用于画面 QA，不写入本地存档。

## 浏览器缩放字体修复

- 根因：浏览器放大导致 CSS 视口落入 `max-width: 1024px` 分支，而该分支将多个标签二次缩小到 6–8px，抵消了浏览器缩放。
- 修复：保留紧凑布局与省略规则，为状态栏、技能、目标协议、科技树和排行榜增加 9–13px 响应式字号下限，并启用 `text-size-adjust: 100%`。
- 不引入 JavaScript 缩放补偿或新依赖；Canvas 战场尺寸、碰撞坐标和游戏逻辑不变。
- 以 960×600 与 720×450 CSS 视口分别复现约 150% 与 200% 缩放触发的响应式分支，战斗 HUD 与科技树均无关键文字遮挡；`npm test` 74/74，200% 科技树页面控制台 0 error。
