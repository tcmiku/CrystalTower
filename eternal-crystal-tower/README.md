# 永耀晶塔

一款原生 Canvas 2D 塔防增量游戏原型。晶塔固定在战场中央并自动射击，玩家鼠标滑过或点击回收金币、沿四分支科技树建立自动化防线、释放四个主动技能，并用阵亡所得星尘强化下一局。

页面支持桌面端、手机竖屏和手机横屏；移动端会自动重排状态栏、战场、快捷控制与技能按钮，并适配刘海屏安全区。

## 运行

需要 Node.js 18 或更高版本。

```powershell
npm.cmd start
```

浏览器打开 [http://127.0.0.1:4173](http://127.0.0.1:4173)。可通过 `?seed=20260824` 指定可复现种子。

使用 `?preview=loading` 可以固定显示素材加载界面，便于视觉检查。
使用 `?preview=tutorial-coin`、`?preview=tutorial-upgrade` 和 `?preview=tutorial-branches` 可以分别检查首局三步引导。

排行榜由同一个 Node.js 进程提供，所有连接该服务器的玩家共享排名。成绩默认持久化到 `data/leaderboard.json`；部署时可用 `LEADERBOARD_FILE=/持久化磁盘/leaderboard.json` 指定数据文件位置，并确保该目录可写。服务器默认监听 `0.0.0.0`，可通过 `HOST` 和 `PORT` 覆盖。

## 操作

- 鼠标滑过或点击战场金币：手动回收；研究无人机与磁吸核心后可逐步自动化。
- 全服排行榜：榜 1 / 榜 2 / 榜 3 使用晶体领奖台视觉突出展示，其余名次保留滚动列表。
- 触屏操作：点击金币或锚点；点击“星落”后，再点击战场方向释放。移动端会自动扩大场内触控判定范围。
- 鼠标或 `1–7`：研究科技树节点。
- `Q`：晶愈，恢复 20% 最大生命。
- `W`：超载，6 秒内攻速翻倍。
- `E`：进入星落手动瞄准，移动鼠标选择扇区，点击战场释放；右键或 `Esc` 取消。
- `F`：金潮归塔，立即吸收战场上的全部金币。
- `T`：打开或关闭科技树；打开面板时自动暂停战斗。
- `P` / `Esc`：暂停或继续。
- 临时遗物三选一：鼠标点击卡片或按 `1 / 2 / 3`；选择期间战斗自动暂停且不能跳过。

## 每局临时遗物

- 每次怪潮精英、普通首领、巨兽命核阶段结束时弹出三选一卡片；同一帧的多份奖励会排队，不会相互覆盖。
- 新存档默认只有 1 个遗物槽，并且只解锁「棱镜护佑」。其余九件机制遗物需要在研究舱使用遗响碎片永久解锁。
- 遗物栏位使用核心残片扩展，费用依次为 2 / 4 / 7 枚，最多 4 格。只有栏位数大于当前已解锁的机制遗物数时，三选一才会用攻击、攻速或双相强化填补缺口。
- 数值强化已收敛为：攻击 +8%、攻速 +6%、双相攻击 +4% 且攻速 +3%，可重复获得。
- 诡光诱饵沿怪潮预告方向生成并接管普通敌人寻路；摧毁后按塔伤爆炸，清空该波敌人后存活则转化金币。
- 月相调律使白昼掉落金币价值 +25%，长夜元素效果 +40%，昼夜切换后获得 6 秒伤害与攻速强化。
- 镜面裂片每 5 次普通齐射折射一次，折射弹不会撞回原目标；主目标为首领时取消折射。
- 余烬回收只响应灼烧或爆炸击杀；余烬区有 12 个性能上限，并会让区内金币按更快时间流逝。
- 遗响碎片由精英掉落，核心残片由普通首领与巨兽掉落；资源必须在战场点击收集。研究舱按配置价格消耗遗响碎片解锁遗物，并消耗核心残片扩展栏位，未解锁遗物不会进入三选一。
- `?preview=relics&seed=42` 可固定打开第一轮卡片选择界面，供响应式与文案检查。
