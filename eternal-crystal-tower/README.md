# 永耀晶塔

一款原生 Canvas 2D 塔防增量游戏原型。晶塔固定在战场中央并自动射击，玩家点击回收金币、沿四分支科技树建立自动化防线、释放四个主动技能，并用阵亡所得星尘强化下一局。

## 运行

需要 Node.js 18 或更高版本。

```powershell
npm.cmd start
```

浏览器打开 [http://127.0.0.1:4173](http://127.0.0.1:4173)。可通过 `?seed=20260824` 指定可复现种子。

## 操作

- 点击战场金币：手动回收；研究无人机与磁吸核心后可逐步自动化。
- 鼠标或 `1–7`：研究科技树节点。
- `Q`：晶愈，恢复 20% 最大生命。
- `W`：超载，6 秒内攻速翻倍。
- `E`：星落，按当前目标协议集中轰击一个方向。
- `F`：金潮归塔，立即吸收战场上的全部金币。
- `T`：打开或关闭科技树；打开面板时自动暂停战斗。
- `P` / `Esc`：暂停或继续。

## 测试

```powershell
npm.cmd test
```

测试覆盖策划数值、目标选择、科技门槛、金币回收、晶刃炮膛、技能、永久研究、存档容错、种子复现、十级首领与十五分钟压力模拟。
