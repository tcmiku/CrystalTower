# 第一章模块数值调整

2026-09-12。覆盖轻炮、重炮、晶刃、机库及元素/混合构筑；本轮主要修正升级收益、机库整备和回旋飞刃叠乘。数值入口为 `src/modules.js` 的 `MODULE_BALANCE`。第二章和旧科技树沿用各自规则。

## 受控伤害对照

30 秒、塔攻击 12、无额外强化/反应器。单体目标距塔 300；近圈群体为 12 个距塔 118 的固定目标，表中群体 DPS 是总和，不能与单体直接比较。首领生命设为十亿且移除修复锚点，避免死亡封顶或回血污染结果。

| 场景 | 调整前 DPS | 调整后 DPS |
|---|---:|---:|
| 重炮 II，远程单体 | 36.01 | 43.22 |
| 重炮 III，远程单体 | 38.62 | 54.07 |
| 重炮 III，首领 | 85.33 | 119.46 |
| 贯星蓄能 III，首领 | 66.47 | 120.10 |
| 晶刃 I，近圈群体 | 642.96 | 711.36 |
| 晶刃 II，近圈群体 | 3378.64 | 1678.94 |
| 晶刃 III，近圈群体 | 10224.81 | 7569.18 |
| 回旋飞刃 III，首领 | 3822.73 | 196.20 |
| 机库 II，远程单体 | 33.61 | 45.78 |
| 机库 III，远程单体 | 49.80 | 79.49 |

三级机库在这组 30 秒测试中的攻击时间占比由 38.8% 增至 58.1%，包含三次耗尽。飞刃首领伤害仍高于普通重炮，但从约 45 倍降到约 1.64 倍；这是固定靶场结果，不能代表所有敌人体积、走位和元素组合。

## 相同策略构筑对照

种子 11、71、20260911；每套 700 起始金币、保留初始轻炮、合法六格装配，先完成构筑，再按最低价格购买核心/模块升级。统一手动收币、治疗、90% 电量再次出击及中性补给策略，不选随机专精。最多运行 900 秒。这里 900 表示达到观测上限，**不表示通关或死亡时间**。

| 构筑 | 调整前观测时长（秒，三个种子） | 调整后观测时长 |
|---|---|---|
| 重炮 | 900 / 900 / 900 | 900 / 900 / 900 |
| 晶刃 | 647.0 / 644.7 / 198.0 | 648.5 / 649.3 / 198.0 |
| 机库 | 641.6 / 638.8 / 764.3 | 637.8 / 639.2 / 752.5 |
| 元素 | 639.0 / 643.7 / 642.9 | 639.0 / 643.7 / 642.9 |
| 混合 | 900 / 900 / 636.4 | 900 / 900 / 900 |

结论：混合构筑在第三个种子中不再提前失败；机库输出改善未转化为这套自动购买策略下的生存提升；晶刃仍有明显的远程覆盖弱点，第三个种子在 198 秒失败。本轮解决了明确的倍率与升级问题，不能据此宣称所有构筑强度相等。此测试保留初始轻炮，但并非从默认 180 金币开局，也没有模拟玩家针对首领换装；需要结合实际游玩继续判断。
