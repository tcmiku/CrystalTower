# 战斗优先 UI 验证

2026-09-12。界面默认使用紧凑 HUD，战场铺满窗口。没有修改战斗数值。

## 改动

- 顶部常驻状态行高 44px；品牌大标题移出战斗视野，账号与公告在展开后可访问。小屏默认保留生命、金币、威胁、时间、暂停和展开入口。
- 战术面板默认收起为 44px 图标按钮，背景只覆盖按钮区域。保留装配、四种目标协议、已解锁的机库切换；机库按钮显示细电量条。短横屏将目标协议排成 2×2。
- 技能栏默认 300×66px，居中靠底，保留技能名、快捷键、就绪状态点及冷却秒数。可展开查看状态；桌面悬停/键盘聚焦可读技能说明。
- 排行榜移至边角。侧栏、技能栏、顶部栏展开均覆盖在画面上，不再挤压战场或改变瞄准坐标。窗口缩放保留当前展开状态。
- 第一章和第二章共用此布局。样式集中在最后加载的 `battle-focus.css`。

## 空间对照

1440×900、相同预览场景：原画布为 1414×818，扣除原侧栏/技能栏预留后，实际战斗视口为 1146×714；新版画布及战斗视口均为 1440×900。可用视口面积增加约 58.4%。该数字比较视口面积，不代表所有 HUD 像素都透明。

## 验证结果

- `npm test`：248 / 248 通过。更新了界面初始类名检查及战场视口测试，完整日志为 `battle-ui-tests.log`。
- 1920×1080、1440×900、1024×720、390×844、844×390：画布覆盖窗口，无横向溢出，常驻按钮在屏幕内。逐张检查真实截图。
- 实际点击/按键验证：Q 生效并显示 30 秒冷却；T 打开装配、关闭后恢复战斗；点击画面中央晶塔打开快速装配；展开侧栏并切换雷达目标协议成功；E 进入瞄准后点击战场成功释放。
- 手机尺寸的顶部、战术和技能详情可以展开/收起，账号入口可访问；横屏四个目标按钮均在可视区域。
- 第二章真实机库按钮将 `attack` 切换为 `collect`，收起状态电量条尺寸 32×3px，正常显示。
- 当前战斗预览无脚本错误。第二章普通入口的原有公告查询 GitHub 提交接口返回一次 403；关闭公告后战斗与 UI 操作正常。
- `git diff --check` 通过。
